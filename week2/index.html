1. HTML Metadata Tags

Essential tags placed inside the <head> element:

  • <html> — The root element enclosing the document.
  • <head> — Container for document metadata.
  • <title> — Sets the page title in the browser tab.
  • <meta> — Provides structured metadata like charsets and viewports.
  • <link> — Connects external stylesheets.

2. Semantic HTML5 Landmarks
